# Example KPI data log (FICTIONAL)

`kpi_log.csv` belongs to the fictional "Example Manufacturing Co." used across `sustainkit`. All
values are invented for demonstration. The 2025 Scope 1 and location-based Scope 2 totals match the
fictional `sustainkit ghg example` inventory (392.36 t and 486.75 t). Two issues are deliberate so the
report has something to show: water consumption has no 2023 value (gap), and hazardous waste jumps in
2024 (flagged for a data check). Market-based Scope 2 is not in the log because the GHG example has no
contractual factors for it.
