# Example data (fictional)

**Everything in this folder is invented for demonstration.** "Example
Manufacturing Co." does not exist; the assessment scores, survey answers and
stakeholder weights are made up by `examples/make_example_data.py` (seed 2026).
Only the topic names come from a real source: the list of sustainability
matters in ESRS 1, Appendix A, AR 16.

- `example_assessment.xlsx` - sheets `about`, `topics`, `survey`, `weights`
- `csv/` - the same tables as CSV
- `classic_matrix.csv` - a classic stakeholder-importance vs business-impact
  table (1-10 scale), the layout many spreadsheet templates use
