# GHG example activity data (fictional)

`activities.csv` describes an **invented** company ("Example Manufacturing
Co.", the same fictional company as the materiality example). Quantities,
sites and the market-based factor are made up. Only the emission factors
applied to them are real (UK Government GHG Conversion Factors 2025).

Row A9 deliberately has no market-based factor, to show that the
market-based Scope 2 total is reported as incomplete rather than guessed.
