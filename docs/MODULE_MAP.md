# How the modules cover a sustainability-management workbook

Sustainability teams often keep a workbook with one tab per task. The
toolkit is planned so each common tab type becomes a module that can be
scripted, validated and reported. (This is a generic mapping; no third-party
template is reproduced here.)

| Typical workbook area | Module | Status |
|---|---|---|
| Materiality assessment / matrix | `materiality` | available |
| GHG emissions (Scope 1, 2, later 3) | `ghg` | available (Scope 1-2) |
| Environmental, social and governance data logs, year-on-year change | `kpis` | planned |
| KPI selection worksheet | `kpis` | planned |
| Energy audit and renewable-transition ideas | `energy` | planned |
| Water-management practices | `water` | planned |
| Circular-economy checklist | `circularity` | planned |
| Environmental impact assessment (inputs/outputs, impacts, improvements) | `impact` | planned |
| Ethical sourcing steps | `supplychain` | planned |
| Social responsibility audit | `social` | planned |
| ESG governance questions | `governance` | planned |
| Responsible-product checklist | `checklists` | planned |
| Office / site green action plan, initiative tracker | `actions` | planned |
| Community engagement strategy | `stakeholders` | available (register, map, engagement status) |
| Stakeholder communication plan | `stakeholders` | planned (roadmap 16) |
| ESG trend analysis | `risk` | planned |
| Regulatory and stakeholder watchlist | `regwatch` | planned |
| Sustainability-report checklist | `disclosure` | planned |
